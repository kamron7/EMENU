Phone 3D Model — Asset Placeholder
=====================================

Status: No GLB asset present. The engine uses a procedural phone fallback.

To replace with a real CC0 model:
1. Download a CC0-licensed phone GLB from poly.pizza (search "phone", filter CC0)
   or from Khronos glTF sample models / Sketchfab CC0 collection.
2. Place the file at public/models/phone.glb
3. The GLTFLoader path in composables/useHeroPhone3D.ts (marked /* swap */)
   will automatically use it on the next build.
4. Update this file with:
   - Model name
   - Author
   - Source URL
   - License: CC0 1.0 Universal (https://creativecommons.org/publicdomain/zero/1.0/)
